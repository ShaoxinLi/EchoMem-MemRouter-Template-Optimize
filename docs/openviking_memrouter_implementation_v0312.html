OpenViking 0.3.12 侧 MemRouter 对接实现方案

基于 OpenViking 0.3.12/0.3.16 真实代码结构的 fast path 实现

一、OpenViking 现有检索链路（Baseline）

先理解 OpenViking 现有的两条检索路径，才能知道 fast path 该插在哪里。

1.1 链路 A：Find（无 Session）

HTTP Router
server/routers/search.py::find() → POST /api/v1/search/find
SearchService
service/search_service.py::find() → viking_fs.find()
VikingFS
storage/viking_fs.py::find() → 直接构造 TypedQuery(intent="")
HierarchicalRetriever
retrieve/hierarchical_retriever.py::retrieve(typed_query) → 向量检索
返回
FindResult(memories, resources, skills) — 0 VLM tokens

1.2 链路 B：Search（有 Session）

HTTP Router
server/routers/search.py::search() → POST /api/v1/search/search
SearchService
service/search_service.py::search() → viking_fs.search(session=...)
VikingFS
storage/viking_fs.py::search() → IntentAnalyzer.analyze() 生成 QueryPlan
IntentAnalyzer
retrieve/intent_analyzer.py → VLM 调用 (~3K-15K tokens)
HierarchicalRetriever
retrieve/hierarchical_retriever.py::retrieve(typed_query) → 向量检索
返回
FindResult(memories, resources, skills, query_plan)

1.3 关键结论

  • find 已经不调用 IntentAnalyzer，但 intent=""，检索策略很简单。
  • search 在有 session 时才会调用 IntentAnalyzer；无 session 时行为和 find 类似。
  • MemRouter 的 fast path 目标：在 search 链路中跳过 IntentAnalyzer.analyze()，直接用 MemRouter 预计算的 typed_query。

3.2 核心服务 — openviking/service/search_service.py 修改

在 SearchService 中新增 execute_instruction()。该方法完全绕过 IntentAnalyzer，直接构造 TypedQuery 并调用 retriever。

"""Add execute_instruction to SearchService for MemRouter fast path."""

from typing import TYPE_CHECKING, Any, Dict, List, Optional, Union

from openviking.core.uri_validation import validate_optional_viking_uris
from openviking.server.identity import RequestContext
from openviking.storage.viking_fs import VikingFS
from openviking_cli.exceptions import InvalidArgumentError, NotInitializedError
from openviking_cli.retrieve.types import ContextType, FindResult, TypedQuery
from openviking_cli.utils import get_logger

if TYPE_CHECKING:
    from openviking.session import Session

logger = get_logger(__name__)


# ---- Existing SearchService class ----

class SearchService:
    """Semantic search service."""

    def __init__(self, viking_fs: Optional[VikingFS] = None):
        self._viking_fs = viking_fs

    def set_viking_fs(self, viking_fs: VikingFS) -> None:
        self._viking_fs = viking_fs

    def _ensure_initialized(self) -> VikingFS:
        if not self._viking_fs:
            raise NotInitializedError("VikingFS")
        return self._viking_fs

    # ---- Existing methods (search, find) unchanged ----

    async def search(...): ...
    async def find(...): ...

    # ---- NEW: execute_instruction for MemRouter fast path ----

    async def execute_instruction(
        self,
        query: str,
        ctx: RequestContext,
        target_uri: Union[str, List[str]] = "",
        search_mode: str = "find",
        context_type: Optional[str] = "memory",
        limit: int = 10,
        score_threshold: Optional[float] = None,
        filter: Optional[Dict] = None,
        typed_query: Optional[Dict[str, Any]] = None,
    ) -> Any:
        """Execute a pre-computed instruction without IntentAnalyzer.

        This is the fast path for MemRouter-confident queries.
        All intent analysis has already been done by MemRouter;
        OpenViking only needs to execute the retrieval.

        Args:
            query: Raw user query
            ctx: Request context (for ACL / telemetry)
            target_uri: Target directory URI(s)
            search_mode: "find" or "search" (determines session handling)
            context_type: "memory" | "resource" | "skill"
            limit: Max results
            score_threshold: Score threshold
            filter: Metadata filters
            typed_query: Optional MemRouter-generated typed query dict
                containing intent, priority, entities, etc.

        Returns:
            FindResult — same shape as search() / find()
        """
        _ensure_non_empty_query(query)
        target_uri = validate_optional_viking_uris(target_uri, field_name="target_uri")
        viking_fs = self._ensure_initialized()

        # Map string context_type to ContextType enum
        ctx_type_map = {
            "memory": ContextType.MEMORY,
            "resource": ContextType.RESOURCE,
            "skill": ContextType.SKILL,
        }
        ctx_type = ctx_type_map.get(context_type or "memory", ContextType.MEMORY)

        # Build TypedQuery from instruction (skip IntentAnalyzer entirely)
        intent = ""
        priority = 1
        if typed_query:
            intent = typed_query.get("intent", "")
            priority = typed_query.get("priority", 1)

        target_uri_list = [target_uri] if isinstance(target_uri, str) else (target_uri or [])

        typed_queries = [
            TypedQuery(
                query=query,
                context_type=ctx_type,
                intent=intent,
                priority=priority,
                target_directories=target_uri_list,
            )
        ]

        # Retrieve (same logic as VikingFS.search / find)
        from openviking.retrieve.hierarchical_retriever import HierarchicalRetriever

        storage = viking_fs._get_vector_store()
        embedder = viking_fs._get_embedder()
        retriever = HierarchicalRetriever(
            storage=storage,
            embedder=embedder,
            rerank_config=viking_fs.rerank_config,
            retrieval_config=viking_fs.retrieval_config,
        )

        async def _execute(tq: TypedQuery):
            real_ctx = viking_fs._ctx_or_default(ctx)
            return await retriever.retrieve(
                tq,
                ctx=real_ctx,
                limit=limit,
                score_threshold=score_threshold,
                scope_dsl=filter,
            )

        query_results = await asyncio.gather(*[_execute(tq) for tq in typed_queries])

        # Aggregate results to FindResult (same as VikingFS.search)
        memories, resources, skills = [], [], []
        for result in query_results:
            for matched in result.matched_contexts:
                if matched.context_type == ContextType.MEMORY:
                    memories.append(matched)
                elif matched.context_type == ContextType.RESOURCE:
                    resources.append(matched)
                elif matched.context_type == ContextType.SKILL:
                    skills.append(matched)

        find_result = FindResult(
            memories=memories,
            resources=resources,
            skills=skills,
            query_results=query_results,
        )
        return find_result

设计要点：

  • 直接复用 VikingFS 的 storage、embedder、retriever 初始化逻辑，确保缓存/ACL/审计不受影响。
  • typed_query 来自 MemRouter 的 instruction，其中 intent 和 priority 直接注入 TypedQuery。
  • 结果聚合逻辑与 VikingFS.search() 完全一致，输出格式完全相同。

3.3 HTTP 路由 — openviking/server/routers/search.py 修改

在现有 search router 中新增 POST /api/v1/search/execute_instruction。

"""Add execute_instruction endpoint to search router."""

from fastapi import APIRouter, Depends
from pydantic import BaseModel, Field
from typing import Any, Dict, List, Optional, Union

from openviking.server.auth import get_request_context
from openviking.server.dependencies import get_service
from openviking.server.identity import RequestContext
from openviking.server.models import Response
from openviking.server.telemetry import run_operation
from openviking.telemetry import TelemetryRequest
from openviking.utils.search_filters import merge_time_filter
from openviking_cli.exceptions import InvalidArgumentError


# ---- Existing classes (FindRequest, SearchRequest, etc.) ----

# ---- NEW: ExecuteInstructionRequest ----

class ExecuteInstructionRequest(BaseModel):
    """Request for execute_instruction (MemRouter fast path)."""

    query: str
    search_mode: str = Field(default="find", pattern=r"^(find|search)$")
    skip_intent_analysis: bool = True
    target_uri: Optional[Union[str, List[str]]] = None
    context_type: Optional[str] = "memory"
    level: Optional[List[int]] = None
    limit: int = Field(default=10, ge=1, le=100)
    score_threshold: Optional[float] = None
    typed_query: Optional[Dict[str, Any]] = None
    filter: Optional[Dict[str, Any]] = None
    telemetry: TelemetryRequest = False


# ---- Existing endpoints (/find, /search, /grep, /glob) unchanged ----

# ---- NEW: /execute_instruction ----

@router.post("/execute_instruction")
async def execute_instruction(
    request: ExecuteInstructionRequest,
    _ctx: RequestContext = Depends(get_request_context),
):
    """Execute a pre-computed memory query instruction (MemRouter fast path).

    This endpoint bypasses IntentAnalyzer entirely. The caller (MemRouter)
    is responsible for having already determined:
        - target_uri
        - search_mode (find / search)
        - context_type (memory / resource / skill)
        - intent, priority (via typed_query)
    """
    service = get_service()
    actual_limit = node_limit if node_limit is not None else request.limit

    execution = await run_operation(
        operation="search.execute_instruction",
        telemetry=request.telemetry,
        fn=lambda: service.search.execute_instruction(
            query=request.query,
            ctx=_ctx,
            target_uri=request.target_uri or "",
            search_mode=request.search_mode,
            context_type=request.context_type,
            limit=actual_limit,
            score_threshold=request.score_threshold,
            filter=request.filter,
            typed_query=request.typed_query,
        ),
    )

    result = execution.result
    if hasattr(result, "to_dict"):
        result = result.to_dict(include_provenance=False)
    result = _sanitize_floats(result)
    return Response(
        status="ok",
        result=result,
        telemetry=execution.telemetry,
    ).model_dump(exclude_none=True)

3.4 HTTP 客户端 — openviking_cli/client/http.py 修改

在 AsyncHTTPClient 中新增 execute_instruction()，使 MemRouterVikingClient 可以一行调用。

"""Add execute_instruction to AsyncHTTPClient."""

# ---- Existing imports ----
from openviking_cli.retrieve.types import FindResult


class AsyncHTTPClient(BaseClient):
    # ---- Existing __init__, initialize, close, etc. unchanged ----

    # ---- Existing methods (find, search, grep, glob) unchanged ----

    # ---- NEW: execute_instruction for MemRouter fast path ----

    async def execute_instruction(
        self,
        instruction: Dict[str, Any],
    ) -> FindResult:
        """Execute a pre-computed BackendQueryInstruction (MemRouter fast path).

        Args:
            instruction: Dictionary conforming to ExecuteInstructionRequest.
                Expected keys:
                    - query: str
                    - search_mode: str ("find" | "search")
                    - skip_intent_analysis: bool
                    - target_uri: Optional[str | List[str]]
                    - context_type: Optional[str]
                    - level: Optional[List[int]]
                    - limit: int
                    - score_threshold: Optional[float]
                    - typed_query: Optional[dict]
                    - filter: Optional[dict]

        Returns:
            FindResult with memories, resources, skills.

        Raises:
            httpx.HTTPStatusError: If server returns 4xx/5xx.
            OpenVikingError: If response contains error status.
        """
        response = await self._http.post(
            "/api/v1/search/execute_instruction",
            json=instruction,
        )
        response_data = self._handle_response_data(response)
        return FindResult.from_dict(response_data.get("result") or {})

注意：MemRouterVikingClient 通过 self._viking.client 访问 HTTP client。如果 VikingClient 使用 _client 私有属性，需要在 VikingClient 中暴露一个 client property，或者修改 MemRouterVikingClient 同时尝试 client 和 _client。

八、总结

基于 OpenViking 0.3.12/0.3.16 真实代码，fast path 只需三个修改：

  1. SearchService 新增 execute_instruction()：直接构造 TypedQuery（intent/priority 来自 MemRouter），调用 HierarchicalRetriever.retrieve()，完全绕过 IntentAnalyzer。
  2. 新增 HTTP endpoint POST /api/v1/search/execute_instruction：接收 instruction，调用 SearchService.execute_instruction()。
  3. AsyncHTTPClient 新增 execute_instruction()：让 MemRouterVikingClient 一行调用。

全部修改是纯新增，不改动现有 search/find/commit 链路，具备完整向后兼容。
