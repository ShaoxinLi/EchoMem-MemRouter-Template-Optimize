MemRouter + OpenViking Agent 集成方案

Agent（higo / openclaw / 其他）如何调用 MemRouter 进行记忆检索

一、核心问题

MemRouter 和 OpenViking 已经对接完成，现在需要回答：Agent 怎么用起来？

Agent 需要解决四个问题：

  1. 何时触发记忆检索？（每个用户消息都检？还是只检记忆相关 query？）
  2. 如何调用MemRouter？（直接调 pipeline？还是封装 SDK？）
  3. 如何消费检索结果？（注入 system prompt？作为 tool result？）
  4. session 上下文怎么传递？（什么时候给 OpenViking 传 session，什么时候不传？）

二、Agent 记忆检索架构

2.1 总体流程

+---------------+      +-------------------+      +-------------------+      +---------------+
|   User        |      |   Agent           |      |   MemRouter       |      |   OpenViking  |
|               |      |   (higo/openclaw) |      |   (EchoMem)       |      |   (VikingFS)  |
+---------------+      +-------------------+      +-------------------+      +---------------+
      |                        |                         |                         |
      |  "我喜欢蓝色"           |                         |                         |
      |----------------------->|                         |                         |
      |                        |  ① 判断是否需要记忆检索   |                         |
      |                        |     (MemoryTriggerGate)  |                         |
      |                        |                         |                         |
      |                        |  ② 调用 MemRouter.route()|                         |
      |                        |------------------------>|                         |
      |                        |                         |  ③ 模板匹配 + 决策        |
      |                        |                         |     生成 query_instructions|
      |                        |<------------------------|                         |
      |                        |                         |                         |
      |                        |  ④ 根据 skip_intent_analysis 选择调用路径            |
      |                        |     ├─ true  → execute_instruction()  [零VLM]      |
      |                        |     └─ false → search(session_info=...) [VLM]       |
      |                        |---------------------------------------------------->|
      |                        |                         |                         |
      |                        |<----------------------------------------------------|
      |                        |     ⑤ 返回 FindResult (memories/resources/skills)   |
      |                        |                         |                         |
      |                        |  ⑥ 结果注入 Agent Context                           |
      |                        |     (system_prompt / memory_context / tool_result)   |
      |                        |                         |                         |
      |                        |  ⑦ LLM 生成回复（带记忆上下文）                      |
      |                        |                         |                         |
      |  "我记得你喜欢蓝色"      |                         |                         |
      |<-----------------------|                         |                         |
      |                        |                         |                         |

2.2 关键设计原则

原则说明
对 Agent 透明Agent 不需要知道 MemRouter 内部有几种后端，只需要调用统一的 retrieve_memory() 接口
检索与生成解耦记忆检索在 LLM 生成之前完成，检索结果作为上下文注入，不改变 LLM 的生成逻辑
session 上下文自动管理Agent 的 conversation history 自动压缩为 session_summary，由 SDK 决定是否传递给后端
可观测每次记忆检索的路由决策、查询指令、检索结果都记录到 trace，方便调试

三、Agent SDK 封装层

3.1 为什么需要 SDK 封装？

Agent 开发者不应该直接操作 MemRouter 的 MemRouterPipeline、BackendQueryInstruction、OpenVikingAdapter 等内部概念。需要一个面向 Agent 的薄封装层：

Agent 开发者视角：
    memory_client = AgentMemoryClient.from_config(config)
    memory_context = await memory_client.retrieve(
        query=user_message,
        conversation_history=messages,  # Agent 自动提供
    )
    # memory_context 是一个字符串或结构化结果，直接注入 prompt 即可

不需要关心：
    - TemplateMatcher 怎么打分
    - RouteDecision 走哪个分支
    - OpenViking 的 IntentAnalyzer 是否被跳过
    - 多个 backend 怎么并行执行

3.2 SDK 接口设计

# echomem/agent_sdk/memory_client.py

from dataclasses import dataclass
from typing import List, Optional, Dict, Any
import asyncio


@dataclass
class MemoryContext:
    """Agent 可直接消费的记忆上下文。"""
    text: str                          # 格式化后的记忆文本，可直接注入 prompt
    sources: List[Dict[str, Any]]      # 来源信息（URI、score、backend_id 等）
    retrieval_trace: Dict[str, Any]    # 检索过程元数据（调试/观测用）
    query_plan: Optional[Dict] = None  # OpenViking 的 query_plan（如走 VLM 路径）


class AgentMemoryClient:
    """Agent 侧记忆检索客户端。

    封装了 MemRouter + OpenViking 的完整调用链路，对 Agent 暴露极简接口。

    Usage:
        client = AgentMemoryClient.from_config({
            "embedder": {"provider": "sentence-transformers", "model": "all-MiniLM-L6-v2"},
            "openviking": {"base_url": "...", "api_key": "..."},
        })

        memory_ctx = await client.retrieve(
            query="你还记得我喜欢什么颜色吗",
            conversation_history=[
                {"role": "user", "content": "我的生日是 5 月 20 日"},
                {"role": "assistant", "content": "好的，我记下了。"},
                {"role": "user", "content": "你还记得我喜欢什么颜色吗"},
            ],
        )

        # 注入到 system prompt
        system_prompt = f"""You are a helpful assistant.
        Relevant memories from previous conversations:
        {memory_ctx.text}
        """
    """

    def __init__(
        self,
        memrouter_pipeline: "MemRouterPipeline",
        backend_executors: Dict[str, Any],  # backend_id -> executor client
        session_compressor: Optional[Any] = None,
    ):
        self._pipeline = memrouter_pipeline
        self._executors = backend_executors
        self._session_compressor = session_compressor

    # ------------------------------------------------------------------ #
    # Public API
    # ------------------------------------------------------------------ #

    async def retrieve(
        self,
        query: str,
        conversation_history: Optional[List[Dict[str, str]]] = None,
        max_memories: int = 5,
        include_trace: bool = False,
    ) -> MemoryContext:
        """Agent 调用记忆检索的统一入口。

        Args:
            query: 当前用户 query（或最后一条用户消息）。
            conversation_history: 完整对话历史，用于 session 压缩和上下文传递。
            max_memories: 最多返回多少条记忆。
            include_trace: 是否在结果中包含详细的检索 trace。

        Returns:
            MemoryContext: 格式化后的记忆文本 + 来源信息。
        """
        # Step 1: 调用 MemRouter 做路由 + 生成查询指令
        route_result = self._pipeline.route(query)

        if not route_result.query_instructions:
            # MemRouter 没有生成查询指令（无匹配模板且无 adapter fallback）
            return MemoryContext(
                text="",
                sources=[],
                retrieval_trace={"route_result": route_result.model_dump()},
            )

        # Step 2: 并行执行所有 backend 的查询指令
        backend_results = await self._execute_instructions(
            route_result=route_result,
            conversation_history=conversation_history,
        )

        # Step 3: 合并、排序、截断结果
        merged_memories = self._merge_results(backend_results, max_memories)

        # Step 4: 格式化为 Agent 可消费的文本
        memory_text = self._format_memories(merged_memories)

        trace = {
            "route_result": route_result.model_dump(),
            "query_instructions": [i.model_dump() for i in route_result.query_instructions],
            "backend_results": {bid: len(r.get("memories", [])) for bid, r in backend_results.items()},
        }

        return MemoryContext(
            text=memory_text,
            sources=merged_memories,
            retrieval_trace=trace if include_trace else {},
            query_plan=backend_results.get("openviking_memory_backend", {}).get("query_plan"),
        )

    # ------------------------------------------------------------------ #
    # Internal helpers
    # ------------------------------------------------------------------ #

    async def _execute_instructions(
        self,
        route_result: "MemBackendRouteResult",
        conversation_history: Optional[List[Dict[str, str]]],
    ) -> Dict[str, Dict[str, Any]]:
        """并行执行所有 query_instructions，返回各 backend 的原始结果。"""

        async def _execute_one(inst: "BackendQueryInstruction") -> tuple:
            backend_id = inst.backend_id
            executor = self._executors.get(backend_id)
            if executor is None:
                return backend_id, {"error": f"No executor registered for backend {backend_id}"}

            # 决策：是否传递 session_info
            # - 如果 skip_intent_analysis=true：不需要 session（MemRouter 已经决定了意图）
            # - 如果 skip_intent_analysis=false：需要 session 给 OpenViking 做意图分析
            session_info = None
            if not inst.skip_intent_analysis and conversation_history:
                session_info = self._build_session_info(conversation_history)

            try:
                result = await executor.execute(inst, session_info=session_info)
                return backend_id, result
            except Exception as e:
                return backend_id, {"error": str(e)}

        tasks = [_execute_one(inst) for inst in route_result.query_instructions]
        results = await asyncio.gather(*tasks)
        return {bid: res for bid, res in results}

    def _build_session_info(
        self, conversation_history: List[Dict[str, str]]
    ) -> Dict[str, Any]:
        """将 Agent 的对话历史压缩为 OpenViking 需要的 session_info。"""
        # 如果有 session_compressor，使用它生成 summary
        if self._session_compressor:
            summary = self._session_compressor.compress(conversation_history)
        else:
            # 简单 fallback：取最近 N 条消息
            summary = ""

        recent_messages = conversation_history[-5:] if len(conversation_history) > 5 else conversation_history

        return {
            "latest_archive_overview": summary,
            "current_messages": recent_messages,
        }

    def _merge_results(
        self,
        backend_results: Dict[str, Dict[str, Any]],
        max_memories: int,
    ) -> List[Dict[str, Any]]:
        """合并多个 backend 的结果，按 score 排序，截断。"""
        all_memories = []
        for backend_id, result in backend_results.items():
            if "error" in result:
                continue
            for mem in result.get("memories", []):
                mem["_backend_id"] = backend_id
                all_memories.append(mem)

        # 按 score 降序排序
        all_memories.sort(key=lambda m: m.get("score", 0), reverse=True)
        return all_memories[:max_memories]

    @staticmethod
    def _format_memories(memories: List[Dict[str, Any]]) -> str:
        """将记忆列表格式化为自然语言文本，便于注入 prompt。"""
        if not memories:
            return ""

        lines = ["=== Relevant Memories ==="]
        for i, mem in enumerate(memories, 1):
            abstract = mem.get("abstract", "")
            category = mem.get("category", "")
            backend = mem.get("_backend_id", "unknown")
            lines.append(f"{i}. [{backend}] {category}: {abstract}")
        lines.append("=== End of Memories ===")
        return "\n".join(lines)

    @classmethod
    def from_config(cls, config: Dict[str, Any]) -> "AgentMemoryClient":
        """Factory method from configuration dict."""
        # 初始化 MemRouter pipeline
        from echomem.pipeline import MemRouterPipeline
        from echomem.embeddings.sentence_transformers import SentenceTransformersEmbedder

        embedder_config = config.get("embedder", {})
        embedder = SentenceTransformersEmbedder(
            model_name=embedder_config.get("model", "all-MiniLM-L6-v2")
        )
        pipeline = MemRouterPipeline.with_defaults(embedder=embedder)

        # 初始化各 backend executor
        executors = {}
        if "openviking" in config:
            from echomem.agent_sdk.openviking_executor import OpenVikingExecutor
            executors["openviking_memory_backend"] = OpenVikingExecutor(
                config=config["openviking"]
            )

        return cls(
            memrouter_pipeline=pipeline,
            backend_executors=executors,
        )

四、Backend Executor 实现

4.1 OpenViking Executor

Executor 是 Agent SDK 中实际调用后端的组件，每个 backend 一个 executor。

# echomem/agent_sdk/openviking_executor.py

from typing import Any, Dict, Optional

from openviking import OpenVikingClient  # OpenViking SDK


class OpenVikingExecutor:
    """执行 MemRouter 生成的 OpenViking 查询指令。"""

    def __init__(self, config: Dict[str, Any]):
        self._client = OpenVikingClient(
            base_url=config["base_url"],
            api_key=config["api_key"],
        )

    async def execute(
        self,
        instruction: "BackendQueryInstruction",
        session_info: Optional[Dict[str, Any]] = None,
    ) -> Dict[str, Any]:
        """根据 instruction 选择调用路径。"""

        if instruction.skip_intent_analysis:
            # Fast path: 直接执行 instruction，绕过 IntentAnalyzer
            result = await self._client.execute_instruction(
                instruction=instruction.model_dump(),
            )
        else:
            # Normal path: 走 OpenViking 的 search()，传入 session_info
            result = await self._client.search(
                query=instruction.query,
                target_uri=instruction.target_uri or "",
                session_info=session_info,
                limit=instruction.extra_params.get("limit", 10),
                level=instruction.level,
                filter=instruction.filter,
            )

        # 统一返回格式（与 FindResult 兼容）
        return {
            "memories": [
                {
                    "uri": m.uri,
                    "abstract": m.abstract,
                    "score": m.score,
                    "category": m.category,
                    "context_type": m.context_type.value,
                }
                for m in result.memories
            ],
            "resources": [...],  # 同理
            "skills": [...],
            "query_plan": result.query_plan.to_dict() if result.query_plan else None,
            "total": result.total,
        }

4.2 Graph Executor（示例）

# echomem/agent_sdk/graph_executor.py

class GraphExecutor:
    """执行 Graph memory backend 的查询指令。"""

    def __init__(self, config: Dict[str, Any]):
        self._client = GraphClient(config["endpoint"])

    async def execute(self, instruction, session_info=None):
        extra = instruction.extra_params
        result = await self._client.traverse(
            root_entity=extra.get("root_entity_hint"),
            hop_depth=extra.get("hop_depth", 1),
            direction=extra.get("traversal_direction", "both"),
            query=instruction.query,
        )
        return {
            "memories": [
                {"uri": n["id"], "abstract": n["label"], "score": n.get("relevance", 1.0)}
                for n in result["nodes"]
            ],
            "total": len(result["nodes"]),
        }

五、Agent 集成模式

5.1 模式一：System Prompt 注入（推荐）

检索到的记忆作为 system prompt 的一部分，在每次 LLM 调用前注入。

# 伪代码：higo / openclaw Agent 集成

class MemoryAugmentedAgent:
    def __init__(self, memory_client: AgentMemoryClient, llm_client):
        self.memory = memory_client
        self.llm = llm_client

    async def chat(self, user_message: str, conversation: List[Message]) -> str:
        # 1. 检索记忆
        memory_ctx = await self.memory.retrieve(
            query=user_message,
            conversation_history=[{"role": m.role, "content": m.content} for m in conversation],
            max_memories=5,
        )

        # 2. 组装 messages
        messages = [
            {"role": "system", "content": self._build_system_prompt(memory_ctx)},
            *self._convert_conversation(conversation),
            {"role": "user", "content": user_message},
        ]

        # 3. 调用 LLM
        response = await self.llm.chat(messages)
        return response

    def _build_system_prompt(self, memory_ctx: MemoryContext) -> str:
        base = "You are a helpful personal assistant."
        if memory_ctx.text:
            base += f"\n\n{memory_ctx.text}\n\nUse the above memories to personalize your response."
        return base

5.2 模式二：Tool / Function Call

把记忆检索封装为一个 Tool，让 LLM 自己决定何时调用。

# Tool 定义（OpenAI function calling 格式）

MEMORY_RETRIEVAL_TOOL = {
    "type": "function",
    "function": {
        "name": "retrieve_memory",
        "description": "Retrieve relevant memories from the user's long-term memory based on the current query.",
        "parameters": {
            "type": "object",
            "properties": {
                "query": {
                    "type": "string",
                    "description": "The search query for memory retrieval.",
                },
                "max_results": {
                    "type": "integer",
                    "description": "Maximum number of memories to retrieve.",
                    "default": 5,
                },
            },
            "required": ["query"],
        },
    },
}

# Agent 流程
async def chat_with_tool(self, user_message, conversation):
    messages = [...]  # system + history + user

    # 第一次 LLM 调用（可能触发 tool call）
    response = await self.llm.chat_with_tools(messages, tools=[MEMORY_RETRIEVAL_TOOL])

    if response.tool_calls:
        for tool_call in response.tool_calls:
            if tool_call.function.name == "retrieve_memory":
                args = json.loads(tool_call.function.arguments)
                memory_ctx = await self.memory.retrieve(
                    query=args["query"],
                    conversation_history=conversation,
                    max_memories=args.get("max_results", 5),
                )
                # 把 tool result 加入 messages
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": memory_ctx.text,
                })

        # 第二次 LLM 调用（带记忆上下文）
        final_response = await self.llm.chat(messages)
        return final_response.content
    else:
        return response.content

5.3 模式对比

维度System Prompt 注入Tool Call
触发时机每次 user message 自动触发LLM 自主决定是否调用
延迟固定（每次都有检索开销）可变（可能不需要检索）
Token 成本固定（检索 + prompt 注入）可能更低（LLM 不触发则不检索）
召回率高（不遗漏）依赖 LLM 判断（可能遗漏）
实现复杂度低中（需要处理 tool call 轮次）
推荐场景个人助理、客服 Agent（记忆是核心能力）通用 Agent（记忆是增强能力）

六、记忆检索触发策略

6.1 触发时机

并非每个 user message 都需要检索记忆。Agent 需要一个 MemoryTriggerGate 来判断是否触发检索：

# echomem/agent_sdk/trigger_gate.py

class MemoryTriggerGate:
    """决定是否对当前 query 触发记忆检索。"""

    # 简单规则：包含记忆相关关键词
    _MEMORY_KEYWORDS = re.compile(
        r"(记得|以前|之前|上次|你说过|我告诉过|我的|我喜欢|我讨厌|"
        r"remember|before|previously|last time|you said|my favorite|I hate|"
        r"我提到过|我们讨论过)",
        re.IGNORECASE,
    )

    # 排除：明显不需要记忆的问题
    _EXCLUDE_PATTERNS = [
        re.compile(r"^(hi|hello|hey|你好|在吗|谢谢|再见)$", re.IGNORECASE),
        re.compile(r"^\d+[\+\-\*\/]\d+\s*=?\s*$"),  # 纯数学计算
    ]

    @classmethod
    def should_retrieve(cls, query: str, conversation: List[Dict]) -> bool:
        """返回 True 表示应该触发记忆检索。"""
        # 排除短句
        if len(query) < 5:
            return False

        # 排除纯问候/计算
        for pattern in cls._EXCLUDE_PATTERNS:
            if pattern.match(query.strip()):
                return False

        # 包含记忆关键词
        if cls._MEMORY_KEYWORDS.search(query):
            return True

        # 轮次触发：每 N 轮对话强制检索一次（兜底）
        if len(conversation) % 5 == 0:
            return True

        return False

6.2 与 MemRouter 的协同

MemoryTriggerGate 是 Agent 侧的粗筛，MemRouter 是精路由：

User Query
→
TriggerGate
粗筛：是否可能涉及记忆？
→
MemRouter
精路由：哪个后端？什么指令？
→
Backend
执行检索

这样设计的好处：

  • TriggerGate 过滤掉 60-70% 的无关 query（如 "你好"、"谢谢"），减少 MemRouter 调用
  • MemRouter 负责精确判断记忆类型（个人事实 vs 偏好 vs 聚合 vs 聊天回溯）
  • 即使 TriggerGate 误触发（把非记忆 query 放过去），MemRouter 会正确路由到 fallback（通常是默认后端返回空结果）

七、完整集成示例

7.1 higo Agent 集成示例

# higo_agent.py

import asyncio
from echomem.agent_sdk.memory_client import AgentMemoryClient, MemoryContext


class HigoMemoryAgent:
    """集成了 MemRouter + OpenViking 的 higo Agent。"""

    def __init__(self):
        self.memory_client = AgentMemoryClient.from_config({
            "embedder": {"model": "sentence-transformers/all-MiniLM-L6-v2"},
            "openviking": {
                "base_url": "http://localhost:8080",
                "api_key": "sk-xxx",
            },
        })
        self.conversation_history = []

    async def handle_user_message(self, user_message: str) -> str:
        from echomem.agent_sdk.trigger_gate import MemoryTriggerGate

        # ① 判断是否触发记忆检索
        if MemoryTriggerGate.should_retrieve(user_message, self.conversation_history):
            # ② 检索记忆
            memory_ctx = await self.memory_client.retrieve(
                query=user_message,
                conversation_history=self.conversation_history,
                max_memories=5,
                include_trace=True,
            )
            print(f"[Memory] Retrieved {len(memory_ctx.sources)} memories")
            print(f"[Memory] Trace: {memory_ctx.retrieval_trace}")
        else:
            memory_ctx = MemoryContext(text="", sources=[], retrieval_trace={})
            print("[Memory] Skipped retrieval (trigger gate)")

        # ③ 组装 prompt
        system_prompt = self._build_system_prompt(memory_ctx)
        messages = [
            {"role": "system", "content": system_prompt},
            *self._history_to_messages(),
            {"role": "user", "content": user_message},
        ]

        # ④ 调用 LLM（higo 内部封装）
        response = await self._call_llm(messages)

        # ⑤ 更新对话历史
        self.conversation_history.append({"role": "user", "content": user_message})
        self.conversation_history.append({"role": "assistant", "content": response})

        return response

    def _build_system_prompt(self, memory_ctx: MemoryContext) -> str:
        parts = [
            "You are Higo, a personal AI assistant with long-term memory.",
            "You remember facts, preferences, and past conversations with the user.",
        ]
        if memory_ctx.text:
            parts.append(f"\n{memory_ctx.text}\n")
            parts.append("Use the above memories to personalize your response.")
        return "\n".join(parts)

    def _history_to_messages(self):
        return [
            {"role": m["role"], "content": m["content"]}
            for m in self.conversation_history[-20:]  # 最近 20 轮
        ]

    async def _call_llm(self, messages):
        # higo 内部 LLM 调用
        from higo.llm import chat_completion
        return await chat_completion(messages, model="gpt-4")


# 运行
async def main():
    agent = HigoMemoryAgent()

    print(await agent.handle_user_message("我的生日是 1990 年 5 月 20 日"))
    # → "好的，我记住了。"

    print(await agent.handle_user_message("你还记得我喜欢什么颜色吗"))
    # → [Memory] Retrieved 1 memories

十一、MemRouter 作为 OpenViking 上层封装（VikingBot 模式）

11.1 核心思路

MemRouter 不需要重新发明一套 Agent 接口，而是可以包装现有的 VikingClient，对 Claw / VikingBot 保持接口完全兼容。

Agent 只需把 VikingClient 替换为 MemRouterVikingClient，其他代码零改动。

11.2 架构关系

┌─────────────────────────────────────────────────────────────┐
│  VikingBot / Claw Agent                                     │
│  ─────────────────────────────────────────────────────────  │
│  client.search(query)     ← 接口不变                         │
│  client.commit(session_id, messages)  ← 接口不变             │
│  client.find(query)       ← 接口不变                         │
│  client.read_content(uri) ← 接口不变                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  MemRouterVikingClient （增强层）                            │
│  ─────────────────────────────────────────────────────────  │
│  search() → MemRouter.route() → 选择 fast / normal 路径     │
│  commit() → 直接透传到底层 VikingClient.commit()            │
│  find()   → 直接透传（或走 MemRouter fast path）             │
│  其他方法  → 全部透传                                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  VikingClient （OpenViking 原生客户端）                       │
│  ─────────────────────────────────────────────────────────  │
│  client.search()  →  VikingFS.search()  (IntentAnalyzer)    │
│  client.find()    →  VikingFS.find()    (直接检索)           │
│  client.commit()  →  Session.add_message() + commit()       │
└─────────────────────────────────────────────────────────────┘

11.3 为什么不是替代，而是封装？

方法VikingClient 原有行为MemRouterVikingClient 增强行为
search() 直接调用 OpenViking VikingFS.search()，总是走 IntentAnalyzer（~3K-15K tokens） 先调用 MemRouter 路由：高置信则走 execute_instruction()（零 VLM）；低置信则回退到原 search()
find() 直接调用 VikingFS.find()，无 session，无 IntentAnalyzer 直接透传（find 本身已是最快路径，MemRouter 不干预）
commit() 创建 session → add_message → commit，写入持久化存储 完全透传。MemRouter 是只读路由层，不参与写入
read_content() 读取 URI 的 L0/L1/L2 内容 完全透传
add_resource() 添加外部资源到 OpenViking 完全透传

11.4 MemRouterVikingClient 实现

# echomem/agent_sdk/memrouter_viking_client.py

import asyncio
from typing import Any, Dict, List, Optional

from loguru import logger

from echomem.pipeline import MemRouterPipeline
from echomem.query_instruction_builder import QueryInstructionBuilder
from echomem.adapters.openviking import OpenVikingAdapter


class MemRouterVikingClient:
    """MemRouter 增强的 VikingClient 封装。

    对 Claw / VikingBot 暴露与 VikingClient 完全兼容的接口，
    内部通过 MemRouter 做路由优化，高置信场景跳过 OpenViking IntentAnalyzer。

    Usage:
        # 原来 VikingBot 的用法：
        # client = VikingClient(agent_id="shared")

        # 替换为 MemRouter 增强版（一行改动）：
        client = MemRouterVikingClient(viking_client=VikingClient(agent_id="shared"))
        await client.initialize()

        # 以下接口完全不变：
        result = await client.search("你还记得我喜欢什么颜色吗")
        await client.commit(session_id="xxx", messages=[...])
        result = await client.find("蓝色")
    """

    def __init__(
        self,
        viking_client: Any,  # VikingClient 实例
        memrouter_pipeline: Optional[MemRouterPipeline] = None,
    ):
        self._viking = viking_client
        self._pipeline = memrouter_pipeline
        self._initialized = False

    async def initialize(self):
        """初始化底层 VikingClient + MemRouter Pipeline。"""
        # 初始化底层 VikingClient（如果它需要）
        if hasattr(self._viking, "initialize"):
            await self._viking.initialize()
        elif hasattr(self._viking, "_initialize"):
            await self._viking._initialize()

        # 初始化 MemRouter（如果未提供）
        if self._pipeline is None:
            from echomem.embeddings.sentence_transformers import SentenceTransformersEmbedder
            embedder = SentenceTransformersEmbedder(model_name="all-MiniLM-L6-v2")
            self._pipeline = MemRouterPipeline.with_defaults(embedder=embedder)

        self._initialized = True
        logger.info("MemRouterVikingClient initialized")

    # ==================================================================
    # 增强方法：search — MemRouter 路由优化核心
    # ==================================================================

    async def search(
        self,
        query: str,
        target_uri: Optional[str] = None,
        limit: int = 10,
        **kwargs,
    ) -> Dict[str, Any]:
        """语义搜索（MemRouter 增强版）。

        内部流程：
            1. MemRouter 路由 → 生成 BackendQueryInstruction
            2. 若 skip_intent_analysis=true → 调用 execute_instruction()（零 VLM）
            3. 若 skip_intent_analysis=false → 回退到原 VikingClient.search()
        """
        if not self._initialized:
            raise RuntimeError("MemRouterVikingClient not initialized. Call initialize() first.")

        # Step 1: MemRouter 路由
        route_result = self._pipeline.route(query)
        instructions = route_result.query_instructions

        if not instructions:
            # MemRouter 未生成指令（无匹配模板）→ 回退到原 search
            logger.debug("MemRouter produced no instructions; falling back to VikingClient.search")
            return await self._viking.search(query, target_uri=target_uri, limit=limit, **kwargs)

        # 取 primary backend 的指令（VikingBot 场景通常只有一个后端）
        inst = instructions[0]
        logger.info(
            "MemRouter routed to backend=%s skip_ia=%s search_mode=%s",
            inst.backend_id, inst.skip_intent_analysis, inst.search_mode,
        )

        # Step 2: 根据 MemRouter 决策选择调用路径
        if inst.backend_id == "openviking_memory_backend" and inst.skip_intent_analysis:
            # Fast path: 直接执行 instruction，绕过 IntentAnalyzer
            return await self._execute_instruction_fast(inst, limit=limit)
        else:
            # Normal path: 回退到 VikingClient.search（带 session context）
            return await self._viking.search(query, target_uri=target_uri, limit=limit, **kwargs)

    async def _execute_instruction_fast(
        self,
        instruction: "BackendQueryInstruction",
        limit: int = 10,
    ) -> Dict[str, Any]:
        """Fast path: 直接调用 OpenViking execute_instruction，绕过 IntentAnalyzer。"""
        # 需要底层 OpenViking client 支持 execute_instruction
        ov_client = self._viking.client  # VikingClient 内部的 AsyncHTTPClient

        # 构造 instruction dict
        inst_dict = instruction.model_dump()
        inst_dict["limit"] = limit

        try:
            # 调用 OpenViking 的 execute_instruction（需 OpenViking 侧实现）
            result = await ov_client.execute_instruction(inst_dict)
        except AttributeError:
            # OpenViking 尚未实现 execute_instruction → 优雅降级
            logger.warning("OpenViking execute_instruction not available; falling back to find()")
            return await self._viking.find(
                query=instruction.query,
                target_uri=instruction.target_uri or "",
                limit=limit,
            )

        # 统一返回 VikingClient.search 格式的 dict
        return {
            "memories": [
                self._matched_context_to_dict(m)
                for m in getattr(result, "memories", [])
            ],
            "resources": [
                self._matched_context_to_dict(r)
                for r in getattr(result, "resources", [])
            ],
            "skills": [
                self._matched_context_to_dict(s)
                for s in getattr(result, "skills", [])
            ],
            "total": getattr(result, "total", 0),
            "query": instruction.query,
            "target_uri": instruction.target_uri,
            "_memrouter_meta": {
                "route_method": "template_embedding",
                "skip_intent_analysis": True,
                "backend_id": instruction.backend_id,
            },
        }

    # ==================================================================
    # 透传方法：find / commit / 其他所有方法
    # ==================================================================

    async def find(self, query: str, target_uri: Optional[str] = None, **kwargs):
        """直接透传到底层 VikingClient.find()。"""
        return await self._viking.find(query, target_uri=target_uri, **kwargs)

    async def commit(self, session_id: str, messages: List[Dict[str, Any]], user_id: str = None):
        """直接透传到底层 VikingClient.commit()。MemRouter 不参与写入。"""
        return await self._viking.commit(session_id, messages, user_id=user_id)

    async def read_content(self, uri: str, level: str = "abstract") -> str:
        """直接透传。"""
        return await self._viking.read_content(uri, level=level)

    async def add_resource(self, local_path: str, desc: str) -> Optional[Dict[str, Any]]:
        """直接透传。"""
        return await self._viking.add_resource(local_path, desc)

    async def list_resources(self, path: Optional[str] = None, recursive: bool = False):
        """直接透传。"""
        return await self._viking.list_resources(path=path, recursive=recursive)

    async def search_user_memory(self, query: str, user_id: str):
        """直接透传。"""
        return await self._viking.search_user_memory(query, user_id)

    async def search_memory(self, query: str, user_ids, agent_user_id: str, limit: int = 10):
        """直接透传。"""
        return await self._viking.search_memory(query, user_ids, agent_user_id, limit=limit)

    async def grep(self, uri: str, pattern: str, **kwargs):
        """直接透传。"""
        return await self._viking.grep(uri, pattern, **kwargs)

    async def glob(self, pattern: str, uri: Optional[str] = None):
        """直接透传。"""
        return await self._viking.glob(pattern, uri=uri)

    async def close(self):
        """关闭底层 VikingClient。"""
        if hasattr(self._viking, "close"):
            await self._viking.close()

    # ==================================================================
    # 内部辅助
    # ==================================================================

    @staticmethod
    def _matched_context_to_dict(matched_context: Any) -> Dict[str, Any]:
        """将 MatchedContext 转换为 dict（与 VikingClient 格式兼容）。"""
        return {
            "uri": getattr(matched_context, "uri", ""),
            "context_type": str(getattr(matched_context, "context_type", "")),
            "abstract": getattr(matched_context, "abstract", ""),
            "overview": getattr(matched_context, "overview", None),
            "category": getattr(matched_context, "category", ""),
            "score": getattr(matched_context, "score", 0.0),
            "match_reason": getattr(matched_context, "match_reason", ""),
        }

    # 支持异步上下文管理器
    async def __aenter__(self):
        await self.initialize()
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        await self.close()

11.7 三种调用路径对比（以 VikingBot search 为例）

路径条件VLM Tokens延迟
MemRouter Fast Path 高置信模板命中 + skip_intent_analysis=true 0 ~30-50ms（embedding + 向量检索）
MemRouter Normal Path 命中但 skip_intent_analysis=false（聚合/聊天回溯） ~3K-15K ~200-500ms（VLM + 检索）

11.8 关键设计约束

  • 写入不经过 MemRouter：commit() 直接透传到底层 VikingClient，MemRouter 是只读路由层
  • 接口完全兼容：MemRouterVikingClient 不修改 VikingClient 的任何方法签名
  • 可开关：use_memrouter: false 时行为与原来完全一致，便于 A/B 测试和问题排查
  • 优雅降级：OpenViking 未实现 execute_instruction() 时，自动回退到 find()
