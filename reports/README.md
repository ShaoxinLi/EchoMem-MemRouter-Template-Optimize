# Reports

本目录存放 MemRouter 项目的历史评测报告和可视化 Dashboard。

## 文件说明

| 文件 | 说明 | 来源 |
|------|------|------|
| `memrouter_dashboard.html` | MemRouter v1.4 阶段性里程碑 Dashboard | 手动导出 |
| `locomo_e2e_full_comparison.html` | LoCoMo E2E 全量对比报告 | 评测脚本生成 |

## 使用方式

直接在浏览器中打开 `.html` 文件即可查看完整报告。

## 新增报告

运行评测后，报告默认生成在 `benchmarks/locomo/runs/{timestamp}_locomo_e2e/results/report.md`。
如需保存到本目录，请手动复制并重命名。
